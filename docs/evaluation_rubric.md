# Human evaluation rubric

Five ordinal outcomes were scored from 0 to 2:

1. **Correctness**: correctness relative to the supplied evidence and benchmark reference interpretation.
2. **Faithfulness**: whether material claims are grounded in the supplied evidence.
3. **Completeness**: whether the response addresses the components that can and should be answered from the supplied evidence.
4. **Citation support**: whether cited passages substantively support the associated claims.
5. **Evidence handling**: whether the response appropriately answers, qualifies, limits, or abstains given the evidence available.

Two binary outcomes were also recorded:
- unsupported material claim: YES/NO;
- contradiction with evidence or benchmark interpretation: YES/NO.

The public release contains de-identified consensus labels and scores. Raw reviewer workbooks and reviewer-identifying information are not included.
