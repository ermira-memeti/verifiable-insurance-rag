# Data and redistribution note

The repository contains processed passages and derived research artifacts from publicly cited FEMA Standard Flood Insurance Policy documents. The MIT license applies to the repository's source code only. It does not grant additional rights over third-party source documents or text derived from them.

Before public release, the repository owner should confirm that redistribution of the processed passage text is permitted. If redistribution is not appropriate, remove `data/core/passages.csv` and the `Supplied Evidence` text column from public evaluation files, while retaining passage identifiers, source URLs, hashes, and reconstruction instructions.

Reviewer identities, private reviewer metadata, API credentials, local environment directories, and private calibration materials are intentionally excluded.
